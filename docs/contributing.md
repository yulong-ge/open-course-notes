# 参与贡献

欢迎改进现有讲义或提议新增课程。

## 修正现有内容

适合直接提交 Pull Request 的改动包括：

- 公式、代码或张量 shape 的错误；
- 失效链接、缺失图片或错误的视频区间；
- 明显影响理解的术语、翻译或结构问题；
- 对口误、经验结论或事实边界的更准确说明。

请在说明中写清来源与验证方式。动态榜单、硬件规格、法规或产品行为等可能变化的事实，应注明核验日期。

## 新增课程

新增课程建议使用稳定的目录标识：

```text
docs/courses/<institution>-<course>-<year>/
├── index.md
├── lecture01-topic/
│   ├── index.md
│   └── assets/
└── ...
```

最低要求：

1. 课程必须有合法公开来源和清楚的来源说明。
2. 每节讲义应是结构化教学材料，而非原字幕复制。
3. 公式需说明动机、假设和符号；代码需说明输入输出或 shape。
4. 每个主要章节以“本章小结”收束，整讲以“总结与延伸”结束。
5. 本地图片必须使用相对路径并被实际引用。
6. 不提交原始视频、cookie、下载日志、临时帧或未授权课件源文件。
7. 更新 `mkdocs.yml` 导航，并通过全部检查。

## 本地检查

```bash
uv sync --locked
uv run python scripts/validate_notes.py
uv run mkdocs build --strict
```

## 提交边界

- 不要把第三方材料纳入本项目的原创内容许可。
- 如需引用图表，优先使用必要、清晰且有来源说明的最小范围。
- 权利人提出合理移除或更正请求时，应优先处理。
