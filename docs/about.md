# 项目说明

Open Course Notes 是一个可持续扩展的中文公开课程讲义库。

## 目标

- 将高质量公开课程整理为可以独立阅读的系统讲义。
- 为初学者补齐必要先修，而不是假设读者已经知道术语。
- 让公式、代码、张量形状和系统图都服务于同一条教学论证。
- 保留视频、公开课件和其他来源的可核验线索。
- 用统一校验与在线构建降低长期维护成本。

## 讲义不是逐字稿

课程视频适合听讲，逐字稿适合检索，讲义则需要重建结构。本站内容通常会：

1. 重新划分章节和概念依赖；
2. 把口头跳步补成公式、shape 或数值例子；
3. 将图放在对应解释附近，并标注视频区间；
4. 指出课件口误、ASR 错误和经验结论的适用边界；
5. 用本章小结和最终综合建立可复习的知识图谱。

## AI 与人工审查

讲义制作使用了自动化工具和 AI 辅助，包括字幕分析、结构重写、关键帧筛选和交叉审查。CS336 讲义经过分段分析、素材视觉检查、统一结构验证，以及同一个 Luna 会话的逐份教学充分性审查与修订复审。

AI 辅助不等同于无误。欢迎通过 GitHub Issue 或 Pull Request 报告公式、事实、链接、图片或版权问题。
